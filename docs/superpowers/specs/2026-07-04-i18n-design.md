# warpdrv i18n 国际化设计文档

> **目标**：为 warpdrv 项目添加国际化支持，首期目标语言为英文（en，源语言）和简体中文（zh-CN）。

## 1. 概述

warpdrv 是一个基于 Electron/Tauri 的本地 LLM 管理桌面应用，前端使用 React 19 + Chakra UI v3 + Tailwind v4，后端使用 Express v5。当前项目中约 500+ 处前端硬编码英文字符串和 100+ 处服务端英文错误消息，无任何现有 i18n 基础设施。

## 2. 技术选型

| 决策项 | 选择 | 理由 |
|--------|------|------|
| i18n 库 | react-i18next + i18next | React 生态事实标准，社区最大，TypeScript 类型推断完善 |
| 字符串提取 | i18next-parser v9+ 全自动扫描 | 覆盖 500+ 字符串，效率最高 |
| Key 组织 | namespace 命名空间分文件 | 按页面模块拆分，文件小易维护 |
| 状态持久化 | Zustand + localStorage | 利用现有 store 架构，零额外依赖 |
| 服务端错误 | 错误码 + 客户端映射表 | 解耦服务端和 i18n，不增加后端复杂度 |


### 3.2 数据流

```
用户切换语言 → Zustand locale 状态变更 → localStorage 持久化
    → i18next 检测 language 变化 → 加载对应 namespace JSON
    → 所有 useTranslation() / <Trans> 组件自动刷新
    → Chakra UI LocaleProvider 同步 direction
```

## 4. 组件修改规范

### 4.1 基础替换

```tsx
// 之前 — 硬编码文本
<Button>Save</Button>
<Text>Welcome to warpdrv</Text>
toast.error('Settings saved')

// 之后 — useTranslation hook
const { t } = useTranslation('settings')
<Button>{t('save')}</Button>
<Text>{t('welcomeMessage')}</Text>
toast.error(t('toast.settingsSaved'))
```

### 4.2 Chakra UI 组件属性

```tsx
// 之前
<Switch.Root label="Fixed chat width" />

// 之后
<Switch.Root label={t('fixedWidth')} />
```

### 4.3 数组/枚举标签（主题、状态、排序字段等）

```tsx
// 之前 — 硬编码 label 数组
const themes = [
  { label: 'Dark', value: ETheme.DARK },
  { label: 'Light', value: ETheme.LIGHT },
]

// 之后 — 使用 t() 映射
const THEME_LABELS: Record<ETheme, string> = {
  [ETheme.DARK]: t('theme.dark'),
  [ETheme.LIGHT]: t('theme.light'),
}
```

### 4.4 带插值的字符串

```tsx
// 之前
`${n} model(s) found`

// 之后
t('modelsFound', { count: n })
```

### 4.5 长段落/富文本

```tsx
// 使用 <Trans> 组件保留内联结构
<Trans i18nKey="guide.step1.description">
  A quick walkthrough to get you running...
</Trans>
```

### 4.6 共享组件（如 ConfirmDialog）

```tsx
// 调用方传入已翻译文本
<ConfirmDialog
  title={t('deleteServer')}
  confirmLabel={t('delete')}
/>
```

## 5. Key 命名规范

```json
{
  // 简单文本 — 语义化简短 key
  "save": "Save",
  "cancel": "Cancel",

  // 嵌套分组 — 页面区域
  "navigation": {
    "home": "Home",
    "settings": "Settings"
  },

  // 带插值 — {{ }} 语法
  "modelsFound": "{{count}} model(s) found",
  "updateAvailable": "WarpCore v{{version}} is available",

  // 动作提示 — toast 前缀
  "toast": {
    "settingsSaved": "Settings saved",
    "loginFailed": "Login failed"
  }
}
```

## 6. 服务端错误消息

### 6.1 策略

不新增服务端 i18n 实例。改为**错误码 + 客户端映射表**方案：

```
服务端返回 → { error: "ERROR_CODE", context: {...} }
客户端拦截 → 查表翻译 → Toast/UI 展示
```

## 8. 语言切换入口

在 Settings 页面 `Appearance` 区域新增语言选择下拉框：

```tsx
<Field label={t('language')}>
  <Combobox
    items={[
      { label: 'English', value: 'en' },
      { label: '简体中文', value: 'zh-CN' },
    ]}
    value={locale}
    onChange={setLocale}
  />
</Field>
```

## 9. 实施顺序

| 阶段 | 内容 | 依赖 |
|------|------|------|
| 1 | i18n 基础设施（i18next 配置、parser 配置、I18nProvider、Zustand 变更） | 无 |
| 2 | 自动提取英文 strings → en/*.json | 阶段 1 |
| 3 | 第一轮校验：检查 key 命名一致性、重复/遗漏 | 阶段 2 |
| 4 | 第二轮校验：修正发现的问题，确认所有 namespace 覆盖完整 | 阶段 3 |
| 5 | 组件替换：逐个 namespace 替换硬编码为 t() 调用 | 阶段 4 |
| 6 | zh-CN 翻译：基于 en/*.json 产出中文翻译 | 阶段 5 |
| 7 | 服务端错误码改造（shared 枚举 + server 路由 + 客户端拦截器） | 阶段 1 |
| 8 | Settings 添加语言切换入口 | 阶段 5 |
| 9 | 功能测试：中英文切换、各页面文本验证、边界情况 | 阶段 6-8 |
